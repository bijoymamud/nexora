# Nexora Technologies — Custom Software & AI Development Platform

Enterprise custom software engineering and applied AI systems platform. Built by combining the best UI/UX and architectural strengths of [NeXora](https://qtec.agency/) and [Vivasoft Ltd](https://vivasoftltd.com/).

## Architectural Highlights

- **Anti-AI Craftsmanship**: Human-crafted layout with intentional asymmetry, high-contrast dark-slate canvas (`#0b1118`), vivid lime/emerald accents (`#abce3e`), and authentic engineering case studies.
- **shadcn/ui Patterns & Motion**: Built with Radix UI primitives (`@radix-ui/react-accordion`, `@radix-ui/react-tabs`, `@radix-ui/react-dialog`, `@radix-ui/react-slot`) paired with `tailwindcss-animate` and micro-interactions.
- **Enterprise SEO & Structured Data**: Complete JSON-LD Schema markup for `Organization` and `ProfessionalService`, semantic single `<h1>`, strict `<h2>`/`<h3>` hierarchy, canonical tags, and OpenGraph metadata.
- **4-Stage Collaboration Framework**: Full support for Team Augmentation, Dedicated Agile Squads, End-to-End Product Engineering, and Rapid MVP Launchpads.

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + shadcn/ui custom design tokens
- **Primitives**: Radix UI + Lucide Icons
- **Typography**: Plus Jakarta Sans, JetBrains Mono

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build
npm run build

# Preview production build
npm run preview
```
